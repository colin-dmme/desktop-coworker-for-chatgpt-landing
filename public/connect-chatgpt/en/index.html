CONNECTION GUIDE · 6 STEPS

Connect ChatGPT to Desktop Coworker from start to finish.

Follow these six steps once. Every step includes a screenshot and a direct link, so you do not have to guess where to click.

1

Name the connection and choose a Workspace

In Desktop Coworker, select Add connection and keep Step by step selected.

  • Connection name: choose a name that makes the ChatGPT account easy to recognize.
  • Workspace: choose the folder ChatGPT should start working from first.
Workspace is not an access limit by default. To restrict folder access, use Full form → Safety after setup.

Select Continue.

2

Create a Secure MCP Tunnel

The Tunnel is the secure path that lets ChatGPT on the web find Desktop Coworker running on your computer.

  1. Open the Tunnel page from the wizard.
  2. Select Create tunnel and give it a recognizable name.
  3. Associate it with the correct ChatGPT workspace.
  4. Copy the Tunnel ID beginning with tunnel_.
  5. Paste it into Desktop Coworker and select Continue.
Open OpenAI Tunnels ↗
Creating or managing a Tunnel requires Tunnels Read + Manage. Running it and selecting it in ChatGPT requires Tunnels Read + Use.
3

Create a Runtime API key

This key lets Desktop Coworker authenticate with OpenAI and run the Tunnel.

  1. Open API Keys.
  2. Select Create new secret key.
  3. Name it “Desktop Coworker” or similar.
  4. Copy the key immediately when it appears.
  5. Paste it into Runtime API key and select Continue.
Open OpenAI API Keys ↗
Important: never send, screenshot, or share the Runtime API key. If exposed, revoke it and create a replacement.
4

Create and start the connection on this computer

Once the connection name, Workspace, Tunnel ID, and Runtime API key are ready, select Create & start.

Desktop Coworker saves the profile, starts the MCP Server, starts the Secure Tunnel, and chooses network ports automatically. Wait until the connection shows green Ready/Running.

If you see a port conflict, choose Change ports and retry.

Then select Continue to ChatGPT.

5

Enable Developer mode in ChatGPT

Open ChatGPT using the exact account/workspace you want to connect.

Go to Settings → Security and login → Developer mode and enable Developer mode. If it is already enabled, continue.

Open ChatGPT Settings ↗
An administrator may need to allow Developer mode in company- or organization-managed workspaces.
6

Create a Plugin and select the correct Tunnel

Keep Desktop Coworker running and the connection in Ready/Running state.

  1. Open Settings → Plugins in ChatGPT.
  2. Select + to create a new Developer mode Plugin.
  3. Under Connection, choose Tunnel.
  4. Select the Tunnel from Step 2 or paste its Tunnel ID.
  5. Enter a Plugin name.
  6. Set Authentication to No Auth.
  7. Verify the Tunnel ID and select Create.
Open Plugin setup ↗

After the Plugin is created, return to Desktop Coworker and select Finish.

Verify the connection

Open a new chat. If ChatGPT asks you to enable or connect the Plugin, choose the one you just created and try:

“Use Desktop Coworker to check the computer connection and tell me the current working folder.”

Or: “List the files in the current Workspace without changing anything.” If ChatGPT can call the tools and return local data, setup is complete.

Quick troubleshooting

Start with the symptom before digging through long logs.

SymptomWhat to check
Tunnel is missing in ChatGPTConfirm it is associated with the correct ChatGPT workspace and the account has Tunnels Read + Use.
Cannot create a TunnelCheck Tunnels Read + Manage on OpenAI Platform.
Plugin exists but will not connectMake sure Desktop Coworker is open and Ready/Running, then refresh the Plugin or open a new chat.
Runtime API key failsCreate a new key, copy the full value, and paste it into Desktop Coworker.
Wrong starting folderEdit the connection Workspace.
Need restricted folder accessOpen Full form → Safety and choose the appropriate access scope.

If it still fails, open Logs in Desktop Coworker and review both MCP Server log and Secure Tunnel log.

You do not need to repeat all six steps next time

Open Desktop Coworker, wait for Ready/Running, then use ChatGPT normally. With Auto-start enabled, the connection starts when the app opens.
