Kết nối ChatGPT với Desktop Coworker từ đầu đến cuối.

Làm đúng 6 bước dưới đây một lần. Mỗi bước đều có ảnh minh họa và link mở thẳng tới nơi cần thiết, để bạn không phải tự đoán mình cần bấm ở đâu.

1

Đặt tên kết nối và chọn Workspace

Trong Desktop Coworker, chọn Add connection và giữ tab Step by step.

  • Connection name: đặt tên để bạn nhận ra tài khoản ChatGPT nào đang nối với máy này, ví dụ “ChatGPT cá nhân” hoặc “ChatGPT công việc”.
  • Workspace: chọn thư mục ChatGPT nên bắt đầu làm việc trước, ví dụ D:\ hoặc một thư mục dự án cụ thể.
Workspace không mặc định là giới hạn truy cập. Nó chỉ là nơi ChatGPT ưu tiên bắt đầu. Muốn giới hạn thư mục, sau khi kết nối xong hãy dùng Full form → Safety.

Nhấn Continue.

2

Tạo Secure MCP Tunnel

Tunnel là đường kết nối an toàn giúp ChatGPT trên web tìm thấy Desktop Coworker đang chạy trên máy của bạn.

  1. Nhấn nút mở trang Tunnel trong wizard.
  2. Chọn Create tunnel và đặt tên dễ nhận biết.
  3. Gắn Tunnel với đúng ChatGPT workspace bạn sẽ sử dụng.
  4. Sao chép Tunnel ID bắt đầu bằng tunnel_.
  5. Quay lại Desktop Coworker, dán Tunnel ID rồi nhấn Continue.
Mở OpenAI Tunnels ↗
Để tạo hoặc quản lý Tunnel, tài khoản cần quyền Tunnels Read + Manage. Để chạy Tunnel và chọn nó trong ChatGPT, cần Tunnels Read + Use.
3

Tạo Runtime API key

Key này giúp Desktop Coworker xác thực với OpenAI để vận hành Tunnel.

  1. Mở trang API Keys.
  2. Chọn Create new secret key.
  3. Đặt tên như “Desktop Coworker”.
  4. Copy key ngay khi nó xuất hiện.
  5. Dán vào ô Runtime API key trong wizard rồi nhấn Continue.
Mở OpenAI API Keys ↗
Quan trọng: không gửi, chụp màn hình hoặc chia sẻ Runtime API key. Nếu key bị lộ, hãy thu hồi key cũ và tạo key mới.
4

Tạo và bật kết nối trên máy

Khi tên, Workspace, Tunnel ID và Runtime API key đã đủ, nhấn Create & start.

Desktop Coworker sẽ lưu cấu hình, khởi động MCP Server, mở Secure Tunnel và tự chọn cổng phù hợp. Chờ tới khi kết nối hiện Ready/Running màu xanh.

Nếu gặp xung đột cổng, chọn Change ports and retry để ứng dụng tự cấp cổng trống rồi thử lại.

Khi đã xanh, nhấn Continue to ChatGPT.

5

Bật Developer mode trong ChatGPT

Mở ChatGPT bằng đúng tài khoản/workspace bạn muốn nối.

Vào Settings → Security and login → Developer mode rồi bật Developer mode. Nếu đã bật sẵn, chỉ cần tiếp tục.

Mở ChatGPT Settings ↗
Với workspace do công ty hoặc tổ chức quản lý, quản trị viên có thể phải cấp quyền Developer mode trước.
6

Tạo Plugin và chọn đúng Tunnel

Giữ Desktop Coworker đang chạy và kết nối ở trạng thái Ready/Running.

  1. Mở Settings → Plugins trong ChatGPT.
  2. Nhấn + để tạo Plugin mới ở Developer mode.
  3. Trong Connection, chọn Tunnel.
  4. Chọn Tunnel vừa tạo hoặc dán Tunnel ID từ Bước 2.
  5. Đặt tên Plugin, ví dụ “COLINPC” hoặc “Desktop Coworker”.
  6. Ở Authentication, chọn No Auth.
  7. Kiểm tra lại rồi nhấn Create.
Mở trang tạo Plugin ↗

Sau khi Plugin tạo thành công, quay lại Desktop Coworker và nhấn Finish.

Kiểm tra kết nối đã hoạt động chưa

Mở một chat mới. Nếu ChatGPT hỏi bật hoặc kết nối Plugin vừa tạo, hãy chọn đúng Plugin đó rồi thử:

“Dùng Desktop Coworker kiểm tra kết nối với máy tính và cho tôi biết thư mục làm việc hiện tại.”

Hoặc: “Liệt kê các file trong Workspace hiện tại, không sửa gì.” Nếu ChatGPT gọi được tool và trả về dữ liệu từ máy, bạn đã kết nối xong.

Những lần sau không cần làm lại 6 bước

Mở Desktop Coworker, chờ kết nối Ready/Running rồi dùng ChatGPT như bình thường. Nếu Auto-start đang bật, kết nối sẽ tự khởi động khi ứng dụng mở.
